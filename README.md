# Scorpi — Personal Profile

Personal digital identity for **Scorpi / @jozz7x**, built as a lightweight static experience for GitHub Pages.

## Stack
Vanilla HTML, CSS and JavaScript. No framework, build step, tracking SDK or exposed secret.

## Deploy
In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)`**.

Expected URL: `https://jozz7x.github.io/profile-scorpi/`

## Media
The profile currently uses the GitHub avatar so the site works immediately. The custom Slenderman/Scorpi artwork can replace it later as `assets/avatar.webp` after optimizing it for the web.

The player intentionally ships without copyrighted audio. If you have a licensed audio file, add it under `assets/` and set the `<audio>` source in `index.html`.

## Notes
The current visit threshold is local/browser-only and intentionally privacy-friendly. A real global counter requires a tiny serverless backend or external counter API; do not expose API keys in this repository.
